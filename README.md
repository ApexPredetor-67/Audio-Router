# Audio-Router
This is a code to route different audio files to different pairs of earphones or headphones using a web based application


1)Download the zip file, unzip it and run app.py
2)This starts a local dev server that allows u to open the page itself
3)Open up the global port: http://127.0.0.1:5000
4)Thats it now enjoy....
5)Just use the given audio files or download your own to the file and just type the name of the file in or if it isn't in the folder, just past the file path

ps: this is one of the easier projects don't judge..
